# Touch cursor asset

`touch-cursor.png` is the original 32 by 32 STS1 PC orb used by its touchscreen cursor. It is included unchanged to preserve the reference appearance; it is not original Touch-STS2 artwork.

Source: Slay the Spire, Mega Crit. File size: 845 bytes.

SHA-256: `AB6A47EE0F8742873BC8F17765BF052C3F21EF3AA1A1698EC1188D412242536B`.

The build embeds this image in the mod DLL and verifies its hash. No other game textures or game assemblies are included.
